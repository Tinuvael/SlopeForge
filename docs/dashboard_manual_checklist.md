# Site and Domain dashboard manual checklist

- Site opens its dashboard; KPI totals equal active production Blocks plus active contour events.
- Domain summary navigation opens the selected Domain dashboard.
- Project Lines shows the active Dataset and history; editors can import/update, viewers cannot.
- Domain tabs show interval/result charts, attention areas, recent changes, blast/area tables and a read-only plan overview.
- Production, contour and Assessment Area rows open their existing pages.
- Header, Add menu, filters, tree, dashboards and Archive/Restore show the supplied icons.
- The plan overview has Fit and Project Lines visibility only; it has no draw/edit controls.
- Restart the application and confirm dashboard values are reconstructed unchanged from PostgreSQL.
