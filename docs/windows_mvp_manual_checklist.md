- **Header:** confirm one native menu arrow, visible text `Add`, `Add project` terminology, and Ctrl+F search focus/filtering.
- **Tree:** check icons, filters, selected rows, and Show archived for Blocks, contour blasts, and Assessment Areas.
- **Project / Domain:** open both dashboards.
- **Production:** open a Block; check engineering tabs, Save draft / Complete, and BlastEvent-owned Photos/Documents.
- **Contour:** open the page; check design/execution tabs and Photos/Documents.
- **Assessment:** create/refine/confirm an area; evaluate DAI/FCI; check linked events, attachments, and Edit boundaries.
- **Viewer:** confirm all mutation controls are disabled.
- **Navigation:** repeat Project → Domain → Block → Area → Contour many times; confirm no stack growth, warning, crash, or recursive navigation.
