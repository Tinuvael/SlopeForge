# Localization manual checklist (Windows)

## English
- Start with English and check Header, tree, Block, Contour, Assessment, and Settings.

## Русский
- In Settings → General choose Русский and confirm the restart note appears.
- Restart, then check login/startup, Header, tree, Block, Technical Card, Contour,
  Assessment, attachments, dashboards, and validation messages.
- Return to Settings, choose English, and restart.
- Launch once more and confirm the language choice persisted.

Intentional exceptions: SlopeForge, repository URL, author/copyright proper names, DAI/FCI,
user-entered/imported content, file names, and persisted IDs/enum keys remain unchanged.
